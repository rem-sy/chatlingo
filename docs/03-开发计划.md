# ChatLingo 开发计划

> 节奏按「业余时间推进」估算；每个里程碑结束都产出可安装、可日常使用的版本。

## 里程碑总览

```
M0 工程脚手架 ──→ M1 MVP 输入方向 ──→ M2 输出方向 ──→ M3 引擎生态 ──→ M4 打磨发布
   (~1 周)           (~2-3 周)          (~2 周)          (~2 周)          (~1-2 周)
```

## M0 · 工程脚手架（约 1 周）

- [ ] `pnpm create tauri-app`（Vue 3 + TS 模板）初始化，UnoCSS 接入
- [ ] 多窗口骨架：Quick Bar / Panel / Settings 三窗口装配，无边框 + 置顶 + 穿透配置
- [ ] 全局快捷键插件接入，`Alt+T` 呼出空 Quick Bar（光标附近定位）
- [ ] keyring 封装：密钥读写 API
- [ ] CI：GitHub Actions 拉起 lint + `tauri build`（三平台矩阵先只跑 Windows）
- [ ] 首个 `v0.1.0-alpha` tag

**验收**：任意界面按 `Alt+T`，光标旁出现置顶空输入条，`Esc` 收起，焦点正确归还。

## M1 · MVP：输入方向（约 2-3 周）

- [ ] 引擎抽象 trait + OpenAI 兼容实现（自定义 baseURL/model/key，SSE 流式）
- [ ] 语言检测：脚本启发式（zh/en/ja + 「已是目标语言则直传」）
- [ ] 格式切分与回填：代码块占位符方案 + LLM Prompt v1
- [ ] Quick Bar 完整交互：输入 → 流式译文 → 目标语言胶囊切换（EN/JA）
- [ ] 译文动作：写剪贴板（带防环标记）+ `enigo` 模拟 `Ctrl+V` 自动回填（可关）
- [ ] 托盘常驻：暂停/恢复、退出
- [ ] 设置窗 v1：引擎配置、快捷键、回填开关

**验收**：真实场景中「中文想法 → 英文出现在 ChatGPT 输入框」≤ 2 次按键，全程不切换窗口。

## M2 · 输出方向（约 2 周）

- [ ] 剪贴板监听服务：去抖、防环校验、最小长度/忽略应用过滤
- [ ] 阅读面板：原文/译文对照、流式渲染、代码块 Markdown 安全展示
- [ ] 常驻侧栏模式（钉住）与被动模式（快捷键翻译当前剪贴板）
- [ ] 本地 SQLite 历史：记录、搜索、一键清空

**验收**：复制 agent 的长 Markdown 回复，2 秒内角落出现中文对照，代码块零改动。

## M3 · 引擎生态（约 2 周）

- [ ] DeepL 引擎（纯文本兜底定位，含检测 API）
- [ ] 引擎降级链 + 失败托盘通知；多引擎并行对比视图（参考 Easydict）
- [ ] LRU 译文缓存；请求合并（同文并发只打一次）
- [ ] Prompt v2：按内容类型（代码/文档/口语）自适应 system prompt
- [ ] Ollama 本地模型预设（零配置发现本地端点）

**验收**：拔掉主引擎 API Key，翻译请求自动走 DeepL，用户仅收到一条托盘提示。

## M4 · 打磨与发布（约 1-2 周）

- [ ] 开机自启、单实例、自动更新（tauri-plugin-updater）
- [ ] Windows 安装包签名与商店外分发；macOS 公证；Linux AppImage
- [ ] 性能：冷启动 < 1s、常驻内存 < 80MB
- [ ] 文档站：官网一页 + 使用指南；发布 `v1.0`
- [ ] 仓库转公开，附 Demo GIF

## Backlog（v1.x+ 候选，暂不排期）

- 划词翻译弹窗（选中即译）
- OCR 截图翻译
- 按应用记住方向偏好（终端走 EN、某网站走 JA）
- 双语对话侧栏：自动跟随滚动截取 agent 回复
- CLI 模式（复用 Rust core）
- 插件系统开放第三方引擎

## 工作约定

- 分支：`main` 保护，功能走 `feat/*` 短分支 + squash merge；
- 提交信息：Conventional Commits（中文描述可）；
- 每个里程碑建 GitHub Milestone，任务入 issue，打 `m0`–`m4` 标签；
- 许可证 MIT；严禁复制 GPL/AGPL 参考项目代码（见[开源参考调研](00-开源参考调研.md)）。
