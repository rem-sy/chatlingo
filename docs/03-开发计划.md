## 已完成（回顾）

- **M2 输出方向**：剪贴板监听、对照面板、SQLite 翻译历史

- **M4 打磨·上**：开机自启、数据目录自定义/便携模式、引擎开关式重构、语种联动、

  半透明毛玻璃、面板拖动/缩放/分界线调比例（v0.3.2）

## M5 · 术语库（已完成，v0.4.0）

**目标**：用户维护一份术语表（原文 → 固定译法），翻译时自动注入，保证专有名词、
产品名、技术词汇在所有引擎、所有会话中译法一致。这是把「能用」推向「专业」的关键一步——
日常对话中同一个词今天翻 A 明天翻 B 是大模型翻译最常见的质量痛点。

**实现级设计与实现顺序**：见 [design/GLOSSARY_DESIGN.md](design/GLOSSARY_DESIGN.md)；
开工提示词：[prompts/M5_GLOSSARY_PROMPT.md](prompts/M5_GLOSSARY_PROMPT.md)。

### 功能拆解

- [x] **数据模型与存储**：`glossary` 表（术语原文、译文、备注、方向、启用状态），
  SQLite 与 history.db 同库；导入/导出 JSON/CSV（迁移与备份）
- [x] **术语管理窗口**：独立窗口（托盘入口），列表 + 搜索 + 增删改 + 批量导入；
  术语冲突检测（同原文多条不同译文时提示）
- [x] **Prompt 注入（大模型）**：翻译前检索命中的术语（原文子串匹配，大小写不敏感），
  以「术语表：A→B，必须严格遵守」形式注入 system prompt；注意 token 上限，
  命中过多时按匹配长度排序截断
- [x] **传统引擎适配**：DeepL 有官方 Glossary API（需先创建术语表资源再引用翻译）；
  阿里云通用版支持 `Context` 参数，注入术语上下文；不可用引擎退化为「译后替换校验」
- [x] **译后校验（兜底）**：对传统引擎译文做术语一致性检查，未命中术语以高亮提示
  （不强行替换，避免破坏语法）
- [x] **设置项**：术语库总开关、单条术语启停、最大注入条数

### 验收

- [x] 术语表含「RAG → 检索增强生成」，输入「帮我实现一个 RAG 系统」，
  三种引擎译文均出现「检索增强生成」且不出现其他译法
- [x] 术语增删后立即生效（无需重启）
- [x] 100+ 条术语时 Prompt 注入有截断策略，翻译延迟无可感知劣化

## M6 · 打磨与发布（下一阶段，v0.5.x → v1.0）

**目标**：从「可用」到「可分发」——自动更新、性能达标、v1.0 对外发布。

**更新渠道裁决**（2026-10-28 用户）：**GitHub Releases**。每个 Release 挂
`latest.json`（固定 URL `releases/latest/download/latest.json`）+ minisign 签名的
setup.exe，tauri-plugin-updater 检查/下载/验签/静默安装一条龙；国内代理不稳场景
静默失败 + 「打开 Release 页」兜底。发版流程脚本化（大文件上传走 curl）。

**实现级设计与里程碑**：见 [design/POLISH_DESIGN.md](design/POLISH_DESIGN.md)；
开工提示词：[prompts/M6_POLISH_PROMPT.md](prompts/M6_POLISH_PROMPT.md)。

### 功能拆解

- [ ] **M6a 自动更新（v0.5.0）**：signer 密钥对生成与离线备份 → updater/notification/
  process 插件集成 → 托盘+设置页入口 → 启动静默检查 → 发版脚本 scripts/release.py →
  v0.4.0→v0.5.0 升级全链路实测
- [ ] **M6b 性能（v0.5.x）**：基线测量（v0.4.0 冷启动/内存）→ 懒建窗口
  （settings/history/glossary 首唤起创建）→ Cargo profile + 前端 chunk →
  冷启动 <1s / 常驻 <80MB
- [ ] **M6c 发布工程（v1.0）**：Demo GIF、README 校对、密钥泄漏审计
  （git 历史/截图脱敏）、仓库转公开、v1.0 Release
- [ ] 后置 Backlog：Authenticode 代码签名、macOS/Linux 出包、文档站

### 验收

- v0.4.0 安装版可自动检测/下载/验签/静默升级到 v0.5.0 并重启生效
- 断网/无代理时更新检查静默失败，手动入口有 Release 页兜底
- 性能达标（本机实测，基线数据留档）
- v1.0 仓库公开无密钥泄漏

## Backlog（v1.x+ 候选，暂不排期）

- 按应用记住方向偏好（终端走 EN、某网站走 JA）
- 双语对话侧栏：自动跟随滚动截取 agent 回复
- CLI 模式（复用 Rust core）
- 插件系统开放第三方引擎
- 划词翻译弹窗（选中即译）
- 术语库进阶：按项目/场景多术语表、术语使用统计

## 工作约定

- 分支：`main` 保护，功能走 `feat/*` 短分支 + squash merge；
- 提交信息：Conventional Commits（中文描述可）；
- 每个里程碑建 GitHub Milestone，任务入 issue，打 `m5`/`m6` 标签；
- 引擎语种支持映射在 Rust（`supports_target`）与前端（`SUPPORTED_LANGS`）各一份，新增引擎/语言时两处同步；
- 许可证 MIT；严禁复制 GPL/AGPL 参考项目代码（见[开源参考调研](00-开源参考调研.md)）。
