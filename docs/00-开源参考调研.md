# 开源参考项目调研

> 调研时间：2026-10。ChatLingo 不复制以下任何代码（许可证冲突，见文末），仅借鉴其产品思路、交互范式与技术方案。

## 一、头部项目

### 1. [pot-desktop](https://github.com/pot-app/pot-desktop) — ⭐ 19.4k · Tauri · GPL-3.0 · **已归档**

跨平台划词翻译 + OCR，支持 DeepL / OpenAI / Google 等多引擎，插件化服务架构，提供本地 HTTP 接口供外部调用。

**可借鉴：**
- Tauri 做翻译工具的完整可行性验证：全局快捷键、多窗口（输入窗/识别窗/偏好窗分离）、置顶、鼠标位置弹窗。
- 插件式翻译服务抽象（内置服务 + 第三方服务目录）。
- 跨平台输入法/焦点处理的踩坑经验（issue 区是宝藏）。

**注意：** 2026 年起仓库归档、停止维护——恰恰说明这个赛道有空间留给后继者。

### 2. [nextai-translator](https://github.com/nextai-translator/nextai-translator)（原 openai-translator）— ⭐ 25k · TS · AGPL-3.0

基于 LLM API 的划词翻译，浏览器插件 + 桌面端双形态，流式输出三栏对照（原文/译文/语言检测）。

**可借鉴：**
- LLM 翻译的 Prompt 设计（角色设定 + 格式保留指令）。
- 流式渲染体验：译文逐字出现，长文不等待。
- 「询问语言 → 目标语言」的显式语言对模型。

### 3. [CopyTranslator](https://github.com/CopyTranslator/CopyTranslator) — ⭐ 18.1k · Electron · GPL-2.0

「复制即翻译」范式开创者：监听剪贴板 → 自动翻译 → 悬浮窗对照显示 → 自动复制译文。

**可借鉴：**
- 剪贴板监听 + 去抖 + 忽略规则（避免自己写入的内容触发死循环）——**这是 ChatLingo 剪贴板模式的直接原型**。
- 智能互译：自动检测源语言并翻译到目标语言。
- 「自动复制译文」小功能对工作流减负明显。

### 4. [Easydict](https://github.com/tisfeng/Easydict) — ⭐ 15k · macOS Swift · GPL-3.0

macOS 词典翻译，离线 OCR，15+ 翻译服务聚合，多结果并行对比。

**可借鉴：**
- 多引擎并行请求 + 结果对比视图（同一个词让 LLM 和 DeepL 各翻一次）。
- 服务可用性自动降级（某引擎失败自动切下一个）。

### 5. [沉浸式翻译](https://immersivetranslate.com/)（非开源，商业产品）

浏览器插件，网页双语对照渲染。

**定位启示：** 它解决的是「读网页」，没解决「写输入」；且绑定浏览器 DOM，无法覆盖桌面 agent 客户端（如 Claude Desktop、终端、DSH）。ChatLingo 以系统级悬浮窗切入，与它错位。

## 二、同技术栈的小型项目（架构参考价值最高）

| 项目 | 简介 | 参考点 |
| --- | --- | --- |
| [shizi-translator](https://github.com/XuDaojie/shizi-translator) | Tauri 2 + Rust + Vue 3，灵感来自 macOS Bob | **与 ChatLingo 技术栈完全一致**，可直接参考工程结构与窗口组织 |
| [smart-translator](https://github.com/lugaoyu2005/smart-translator) | Tauri 2，OPUS-MT 离线模型 + 7 在线引擎 | 离线引擎集成方式（Rust 侧跑推理） |
| [hytrans](https://github.com/cunba-ai/hytrans) | Tauri v2 + llama.cpp sidecar，全程本地划词翻译 | sidecar 进程方案：本地 LLM 作为翻译引擎的部署形态 |
| [Glossy](https://github.com/SpencerZXWu/Glossy) | Tauri 2 轻量划词弹窗 | 轻量弹窗交互：选中即出小窗，不抢焦点 |
| [catwalk-translator](https://github.com/maobu_keai/catwalk-translator) | Tauri 2.0 + RapidOCR ONNX，面向创作者 | OCR 能力的引入路径（后续版本可参考） |

## 三、结论：ChatLingo 的差异化生态位

| 维度 | pot | nextai-translator | CopyTranslator | 沉浸式翻译 | **ChatLingo** |
| --- | --- | --- | --- | --- | --- |
| 场景 | 通用划词 | 通用划词 | 阅读外文 | 读网页 | **AI 对话工作流** |
| 方向感知（入译/出译分开） | ✗ | ✗ | ✗ | ✗ | ✓ 核心 |
| Markdown/代码保真 | 部分 | 部分 | ✗ | ✓（网页） | ✓ 核心 |
| 译文回填输入框 | ✗ | ✗ | ✗ | ✗ | ✓ 核心 |
| 桌面级悬浮窗 | ✓ | ✓ | ✓ | ✗ | ✓ |

所有前辈都在解决「把外文翻给我看」，没有人系统解决「我和 agent 互相对话」的双向流水线。**ChatLingo = CopyTranslator 的剪贴板范式 + pot 的 Tauri 工程实践 + nextai 的 LLM 翻译质量，组合出一个新场景。**
