## M5 · 术语库（已完成，v0.4.0）

**目标**：用户维护一份术语表（原文 → 固定译法），翻译时自动注入，保证专有名词、
产品名、技术词汇在所有引擎、所有会话中译法一致。这是把「能用」推向「专业」的关键一步——
日常对话中同一个词今天翻 A 明天翻 B 是大模型翻译最常见的质量痛点。

**实现级设计与实现顺序**：见 [design/GLOSSARY_DESIGN.md](design/GLOSSARY_DESIGN.md)；
开工提示词：[prompts/M5_GLOSSARY_PROMPT.md](prompts/M5_GLOSSARY_PROMPT.md)。

### 功能拆解

- [x] **数据模型与存储**：`glossary` 表（术语原文、译文、备注、方向、启用状态），
  SQLite 与 history.db 同库；导入/导出 JSON/CSV（迁移与备份）
- [x] **术语管理窗口**：独立窗口（托盘入口），列表 + 搜索 + 增删改 + 批量导入；
  术语冲突检测（同原文多条不同译文时提示）
- [x] **Prompt 注入（大模型）**：翻译前检索命中的术语（原文子串匹配，大小写不敏感），
  以「术语表：A→B，必须严格遵守」形式注入 system prompt；注意 token 上限，
  命中过多时按匹配长度排序截断
- [x] **传统引擎适配**：DeepL 有官方 Glossary API（需先创建术语表资源再引用翻译）；
  阿里云通用版支持 `Context` 参数，注入术语上下文；不可用引擎退化为「译后替换校验」
- [x] **译后校验（兜底）**：对传统引擎译文做术语一致性检查，未命中术语以高亮提示
  （不强行替换，避免破坏语法）
- [x] **设置项**：术语库总开关、单条术语启停、最大注入条数

### 验收

- [x] 术语表含「RAG → 检索增强生成」，输入「帮我实现一个 RAG 系统」，
  三种引擎译文均出现「检索增强生成」且不出现其他译法
- [x] 术语增删后立即生效（无需重启）
- [x] 100+ 条术语时 Prompt 注入有截断策略，翻译延迟无可感知劣化

## M6 · 打磨与发布（下一阶段，v0.5.x → v1.0）

**目标**：从「可用」到「可分发」——自动更新、性能达标、v1.0 对外发布。

**更新渠道裁决**（2026-10-28 用户）：**GitHub Releases**。每个 Release 挂
`latest.json`（固定 URL `releases/latest/download/latest.json`）+ minisign 签名的
setup.exe，tauri-plugin-updater 检查/下载/验签/静默安装一条龙；国内代理不稳场景
静默失败 + 「打开 Release 页」兜底。发版流程脚本化（大文件上传走 curl）。

**实现级设计与里程碑**：见 [design/POLISH_DESIGN.md](design/POLISH_DESIGN.md)；
开工提示词：[prompts/M6_POLISH_PROMPT.md](prompts/M6_POLISH_PROMPT.md)。

### 功能拆解

- [x] **M6a 自动更新（v0.5.0，2026-10-28 完成）**：signer 密钥对生成与离线备份
  （公钥指纹 `F7E696C8403A5293`）→ updater/notification/process 插件集成 →

## M8 引擎接口生态（v1.1.0，2026-10-29 完成）

**目标**：大模型渠道支持三种接口格式 + 渠道预设一键填充。

- [x] **接口格式三 adapter**（engines/openai.rs 拆分）：新增配置 `engine.apiFormat`
  （openai-completions 默认 / openai-responses / anthropic-messages，serde 默认值旧配置零迁移）；
  completions 现逻辑不动；responses 走 POST {base}/responses + instructions + SSE
  `response.output_text.delta`/`response.completed`；anthropic 走 POST {base}/v1/messages +
  `x-api-key`/`anthropic-version` 头 + system 顶层字段（术语注入）+ SSE
  `content_block_delta`/`message_stop`；quick_check/list_models 按格式分派
  （anthropic 无模型列表，UI 禁用入口）
- [x] **渠道预设 providers.json**（src-tauri 入库，include_str! 嵌入 + 前端读同一份）：
  DeepSeek / Anthropic / OpenAI（responses）/ Moonshot / 智谱 / 百炼 Qwen / MiniMax
  （anthropic 端点）/ OpenRouter / xAI + 自定义；Anthropic/OpenAI 标注「国内需代理」
- [x] **设置页**：「渠道预设」下拉联动填 baseUrl+apiFormat+模型（可手改）、「接口格式」
  下拉 + 格式说明文案
- [x] **缓存隔离**：译文缓存与 in_flight 合并 key 纳入 apiFormat（单元测试覆盖）；
  preset.json 同步加字段
- [x] **实测**：三格式各接真渠道流式翻译 + 术语注入通过（windhub：completions=glm-4.5-flash
  回归 / responses=grok-4.7 / anthropic-messages=glm-4.5-flash anthropic 端点）

设计：[M8_ENGINE_API_DESIGN.md](archive/design/M8_ENGINE_API_DESIGN.md)（archive 不入库）。
